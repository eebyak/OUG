Not filled in or guessed at — flagged as a genuine gap in the source rather than a conversion artifact.

- [ ] **The OUG Report 2025–26 describes an earlier, different institutional framing** than the rest of this repository — a portfolio of EU/BMBF-funded initiatives (OPEN STUDY, OPEN PATHWAY, VIRTUAL STUDY, DIGITAL STUDY) rather than the governance/quality/strategy architecture converted elsewhere. Kept as historical context per its own value, but worth being clear with any reader that it does not describe the OUG's current institutional design — flagged in the document's own header note.
