The OUG design-pattern catalogue names 42 recurring institutional antipatterns and the structural design patterns developed as their counter-designs.

This page provides a simple index only. The individual pattern documents are maintained in the repository’s **[DesignPatterns directory](https://github.com/eebyak/OUG/tree/main/DesignPatterns)**.

The individual documents are not included in the GitHub Pages publication, but they can be opened and read directly in the GitHub repository through the links below.
